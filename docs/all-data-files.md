| File | Pages | Purpose | Format | Delete on write? |
|------|-------|---------|--------|-----------------|
| Manager.1800 | 25057 | All masters (ledgers, groups, stock, etc) | TLV + fixed | NO - this IS the data |
| TranMgr.1800 | 10409 | All vouchers/transactions | TLV + fixed + amounts | NO - this IS the data |

## File Format Summary

### otype values across all files:
| otype | Meaning | Found in |
|-------|---------|----------|
| 0x0003 | Search key / index entry | TranMgr |
| 0x0005 | Data content (line items, details) | TranMgr |
| 0x0006 | Extended numeric data | ExtMngr, CmpSave |
| 0x0007 | Sparse numeric data | ExtMngr, SecTran, CmpSave |
| 0x0009 | Status record (one per voucher) | VchStatus, StatStatus |
| 0x000A | Narration/notes | TranMgr |
| 0x000B | Object header (main record) | ALL files |
| 0x0042 | Counter/chain/overflow pages | ALL files |

### pidx values (sub-type within otype):
For otype=0x000B:
- pidx=0: Company-level data (in Manager)
- pidx=1: Object header/main record
- pidx=2: Ledger detail pages (in Manager)
- pidx=3: Voucher type pages (in Manager)
- pidx=4+: Additional detail pages

For otype=0x0042:
- pidx=0: Overflow/continuation data
- pidx=1: Counter/summary data
- pidx=2: Metadata (GUID, user, revision)
- pidx=3: Chain pointers
- pidx=4: Compact reference records (10-byte format)

## Writer Strategy

```
On master write (ledger/group/stock):
  1. Modify Manager.1800 (append pages, update header)
  2. Delete: Index.1800, TSTATE.TSF, TUPDATE.TSF, Aggr.1800

On voucher write (sales/purchase/payment):
  1. Modify TranMgr.1800 (append pages)
  2. Modify LinkMgr.1800 (append pages)
  3. Delete: Index.1800, TSTATE.TSF, TUPDATE.TSF, Aggr.1800, VchStatus.1800
```
